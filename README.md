# QUAD: ProVerif Security Verification

**Paper:** *A Lightweight Hybrid Post-Quantum Authentication Protocol for Resource-Constrained UAV–GCS Communications*  
**Tool:** ProVerif 2.05  
**Models:** Six formal models covering 26 queries, plus three event-reachability diagnostic models.

## Formal models and results

| Query IDs | Model file (in `01_Formal_Models/`) | Verification focus | Result |
|---|---|---|---|
| Q1–Q6 | `QUAD_Authenticated_Handshake_Model_Q01-Q06.pv` | Handshake secrecy and authentication | 6 True |
| Q7–Q11 | `QUAD_Authenticated_Rekeying_Model_Q07-Q11.pv` | Authenticated rekeying | 5 True |
| Q12–Q16 | `QUAD_Bounded_Rekey_Retransmission_Model_Q12-Q16.pv` | Bounded R1/R3 retransmissions | 5 True |
| Q17–Q22 | `QUAD_Post_M6_Single_Secret_Disclosure_Model_Q17-Q22.pv` | Historical sessions after one long-term-secret disclosure | 6 True |
| Q23–Q24 | `QUAD_Historical_Telemetry_and_Impersonation_Attack_Model_Q23-Q24.pv` | Historical U2G disclosure and future impersonation | 2 False (counterexamples) |
| Q25–Q26 | `QUAD_Historical_Command_and_Impersonation_Attack_Model_Q25-Q26.pv` | Historical G2U disclosure and future impersonation | 2 False (counterexamples) |

The six model logs contain **22 True and 4 False** results. The four False
results exhibit the specified attack scenarios; they are not successful
security proofs. Q1–Q26 identify the queries in the order they appear
within these six files; they are not identifiers generated by ProVerif.

## Files

- `01_Formal_Models/`: Six `.pv` files for Q1–Q26.
- `02_Reachability_Diagnostics/`: Three additional `.pv` models for event reachability.
- `03_Formal_Verification_Logs/`: ProVerif output for the six formal models.
- `04_Event_Reachability_Logs/`: ProVerif output for the three diagnostic models.
- `SHA256SUMS.txt`: SHA-256 checksums for all model, log, and README files.

## Reproduction

Install **ProVerif 2.05** and execute each model independently. For example,
from the extracted package directory in Windows PowerShell:

```powershell
& 'C:\path\to\proverif.exe' '.\01_Formal_Models\QUAD_Authenticated_Handshake_Model_Q01-Q06.pv'
```

Replace the executable path with the local ProVerif installation path.
Compare the `RESULT` lines to the corresponding files in
`03_Formal_Verification_Logs/`. Diagnostic models can be run the same way;
compare their output with `04_Event_Reachability_Logs/`.

The diagnostic models include **19 additional reachability witness queries**
(10 handshake, 5 retransmission, 4 post-M6 disclosure). They intentionally
make a witness observable after a modeled event. A False result for a
`not attacker(witness)` query indicates reachability of that witness and
**does not indicate a confidentiality failure**. These 19 queries are not
part of Q1–Q26.
